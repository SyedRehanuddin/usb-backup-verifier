Project Information

About USB Backup Verifier

A browser-based CRC-32 verifier that compares folders you select and detects changed, missing, or unexpected files without uploading them.

Version 1.0 Browser CRC-32 mode

What this tool does

Backup integrity verification

Select a trusted source and backup folder manually. After browser permission is granted, CRC-32 is calculated locally and each file is classified as Verified, Corrupted, Missing, or Extra.

Selected files are read only for this browser session and are not uploaded to a server.

Verified Corrupted Missing Extra

How it works

Four-step workflow

  1. 01
    Trusted Source

    Select the original folder from this device.

  2. 02
    Generate Reference

    Create trusted CRC-32 values.

  3. 03
    Select Backup

    Select the backup folder from this device.

  4. 04
    Verify

    Compare the backup with the reference.

Status meanings

Understand each result

Verified

Source and backup match.

Corrupted

The file exists but its CRC-32 differs.

Missing

The source file is absent from the backup.

Extra

The backup contains an unexpected file.

CRC-32

CRC-32 Integrity Check

CRC-32 creates a checksum from file data. If a file changes, its checksum will normally change, allowing accidental corruption to be detected.

CRC-32 is designed for error detection, not cryptographic security.

Trusted reference

Replace trusted reference?

This will replace the saved CRC-32 reference with the currently selected source folder. Future backup checks will use the new reference. Verification History will be preserved.

!

Permanent action

Clear verification history?

This will permanently remove all saved verification records from this device. This action cannot be undone.
